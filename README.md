# خشت نیوز

یک سامانه خبری محلی واقعی و قابل اجرا با Flask، SQLite، Jinja2 و رابط کاربری فارسی RTL.

## امکانات

- سایت عمومی کاملاً RTL و واکنش‌گرا
- دیتابیس واقعی SQLite و ایجاد خودکار جداول
- پنل مدیریت با ورود امن و رمز هش‌شده
- ایجاد، ویرایش و حذف خبر
- پیش‌نویس و انتشار
- دسته‌بندی و جستجوی واقعی
- آپلود تصویر اصلی، چند تصویر اضافی و ویدیو
- نمایش رسانه‌های همان خبر در کارت و صفحه خبر
- CSRF برای فرم‌های POST
- نام‌گذاری تصادفی و امن فایل‌ها
- اعتبارسنجی تصویر با Pillow
- محدودیت حجم آپلود ۶۴ مگابایت
- Empty State بدون هیچ خبر، تصویر یا ویدیوی ساختگی
- SEO پایه، Open Graph و Twitter Card
- اشتراک‌گذاری Copy Link، WhatsApp و Telegram
- تشخیص خودکار اولین فونت موجود در `static/fonts/` با اولویت woff2، woff، ttf، otf
- لوگوی اختیاری `static/images/logo.png` با fallback متنی

## اجرا در Windows

### 1. نصب Python

Python 3.11 یا جدیدتر را نصب کنید.

### 2. ساخت محیط مجازی

```powershell
python -m venv venv
```

فعال‌سازی:

```powershell
venv\Scripts\activate
```

### 3. نصب وابستگی‌ها

```powershell
pip install -r requirements.txt
```

### 4. ساخت مدیر اولیه

رمز عبور داخل کد پروژه ذخیره نمی‌شود. یک‌بار این دستور را اجرا کنید:

```powershell
python app.py --create-admin
```

نام کاربری و رمز را خودتان وارد کنید. اطلاعات رمز به‌صورت هش‌شده در دیتابیس ذخیره می‌شود.

### 5. اجرای سایت

```powershell
python app.py
```

سپس باز کنید:

http://127.0.0.1:5000

پنل مدیریت:

http://127.0.0.1:5000/admin/login

## لوگو

فایل لوگوی خودتان را با نام دقیق زیر قرار دهید:

`static/images/logo.png`

اگر فایل وجود نداشته باشد، سایت خراب نمی‌شود و fallback متنی «خشت نیوز» نمایش داده می‌شود.

## فونت

هر فونت فارسی/انگلیسی با یکی از فرمت‌های زیر را در `static/fonts/` قرار دهید:

- `.woff2`
- `.woff`
- `.ttf`
- `.otf`

نیازی به تغییر CSS نیست؛ اولین فونت طبق اولویت بالا به‌صورت خودکار انتخاب می‌شود.

## فایل‌های آپلودی

- تصاویر: `uploads/images/`
- ویدیوها: `uploads/videos/`

## امنیت و Production

برای محیط عمومی مقدار `KHESHT_SECRET_KEY` را به یک مقدار تصادفی و پایدار تغییر دهید. در صورت استفاده از HTTPS می‌توانید `KHESHT_SECURE_COOKIE=1` قرار دهید.

نمونه PowerShell:

```powershell
$env:KHESHT_SECRET_KEY="یک-کلید-تصادفی-طولانی"
$env:KHESHT_SECURE_COOKIE="1"
python app.py
```

برای Production از یک WSGI server مناسب استفاده کنید و `FLASK_DEBUG` را فعال نکنید.

## قانون محتوا

این پروژه در شروع هیچ خبر، تصویر، ویدیو، خبرنگار یا آمار ساختگی ایجاد نمی‌کند. فقط دسته‌بندی‌های سیستمی برای استفاده در پنل ساخته می‌شوند. تمام محتوای خبری از دیتابیس می‌آید.

## نوار تصویری بالای سایت
برای نمایش یک نوار تصویری باریک در بالای صفحات، فایل خودتان را در مسیر زیر قرار دهید:

`static/images/top-banner.png`

فرمت‌های PNG، JPG، JPEG و WEBP پشتیبانی می‌شوند. نام `top-banner` باید حفظ شود؛ برنامه پسوند مناسب موجود را به‌صورت خودکار پیدا می‌کند. اگر هیچ فایل نوار بالایی وجود نداشته باشد، هیچ تصویر نمونه‌ای نمایش داده نمی‌شود.

راهنمای نام‌گذاری تصاویر در `static/images/README.txt` قرار دارد.
